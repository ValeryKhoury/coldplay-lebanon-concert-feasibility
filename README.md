# Coldplay Concert in Lebanon: Venue Feasibility Study

Consulting project, B.E. Industrial Engineering, Lebanese American University
(Jan 2025 – May 2025)

## Overview
A consulting-style feasibility study on hosting a Coldplay concert in Lebanon.
The team built a financial model to compare two options: renovating an existing
stadium versus constructing a new one.

## Key result
- Under the recommended scenario, the model estimates a profit of **$23.83M**

## Approach
- Built an **Excel financial model** comparing renovation and new construction
- Conducted **market sizing** using international audience data
- Performed **competitive benchmarking** against a Coldplay concert in Dubai to
  inform pricing and demand assumptions

## Tools used
Microsoft Excel, PowerPoint for the final presentation
